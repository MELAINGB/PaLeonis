# PaLeonis - API REST

API REST développée avec **Node.js**, **Express** et **PostgreSQL** pour la gestion de l'infrastructure PaLeonis (datacenters, offres, tickets, clients et serveurs).

---

##  Prérequis

- [Node.js](https://nodejs.org/) (v18 ou supérieur)
- [PostgreSQL](https://www.postgresql.org/)

---

##  Installation et Lancement

###  Cloner et installer les dépendances

npm install


### Pour lancer 
"npm run dev"
aller sur 
http://localhost:3000

### pour tester 
les endpoints sont disponibles dans le docs 

### pour changer la bdd 

cree un bdd sur pg admin et recupere les infos pour les mettre dans le fichier .env  suivant : 

exécuter le schema et le seed pour creer les tables et les données nécessaires
